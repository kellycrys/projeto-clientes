# Sistema de Gestão de Clientes (PF e PJ)

Projeto prático desenvolvido no Instituto Federal de Goiás (IFG) com a turma da EJA.

## Tecnologias Empregadas:
- **Frontend:** HTML5, CSS3 e JavaScript Puro (Padrão MVC)
- **Backend:** Python (Flask) com API REST
- **Banco de Dados:** MySQL (clientes_db)
- **Deploy:** Netlify (Frontend) e Render.com (Backend e BD)
